# Attribution

The kobi_soundbank banks are collections of independently licensed instruments: each program and each drum-kit piece keeps the licence of the library it was built from, listed below.  In every case the samples were trimmed, looped, re-encoded as Ogg Vorbis, levelled, pitch-corrected where a note was off, and mapped to General MIDI keys by kobi_soundbank; soundfont presets were rendered through sfizz first.  The code that builds them is MIT ([LICENSE](LICENSE)).  Generated by `python3 -m kobi.attribution` from the mapping the banks are built from (gm_map with the swipe picks in SWIPE_PICKS.json).

## Before publishing a bank

- **"Classical Acoustic Guitar" SFZ (downloaded 2026-09-22)** (unknown): no author or licence found: find its source or replace it before publishing.  Used by: 024 Acoustic Guitar (nylon).
- **FSS Steel String Guitar (FreePats)** (GNU GPL): copyleft: distribute under the GPL, with the source samples on request.  Used by: 025 Acoustic Guitar (steel).
- **Sonatina Symphonic Orchestra** (CC Sampling Plus 1.0): attribution; the set contains Philharmonia and unknown-provenance recordings, so check each instrument before a public release.
